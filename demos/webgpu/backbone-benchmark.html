⏱️ LocalAgent matched backbone latency

A latency-only comparison of two untrained-random-weight, hidden-only ONNX graphs at exact input-tensor lengths using deterministic pre-tokenized IDs. It makes no language, tool-use, or agent-quality claim and loads no tokenizer asset. The default is an explicit single-provider WebGPU session request; use ?backend=wasm for the separate explicit WASM arm.

Conditions are the Cartesian product of two manifest-pinned hidden-only graphs and 128, 512, 1,024, and 1,536 deterministic pre-tokenized IDs. The ID contract is ids[i]=(131*i+17) mod vocab_size, shared exactly across both graphs. Session creation is separate from the first session.run for each graph and length condition; the earliest condition for each graph is additionally labeled. Three warmups per graph and length are retained but excluded from the thirty-run warm summary. Condition order is seeded and randomized within every repetition. The page requests exactly one session provider and never performs a whole-session retry with another provider. ONNX Runtime does not expose per-node placement here, so the payload labels per-node fallback status as unknown. Reload the page before another run so “first inference” remains literal.

The downloadable payload is also exposed as window.__localAgentBackboneBenchmarkResult for controlled-browser collection. It includes verified graph/config hashes, exact token IDs, bundle/session timings, first-inference records, warmup records, every measured record, and error details.
