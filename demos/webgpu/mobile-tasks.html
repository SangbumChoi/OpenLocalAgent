📱 LocalAgent mobile + productivity loop

A text-first, stateful pilot for Android-style actions plus local email and Notion tool calls. It uses the same WebGPU bundle and schema validation as the demo; it does not claim screenshot grounding, trusted OS input, or access to real accounts.

Loading the WebGPU model…

Scope: deterministic in-memory Android/email/Notion state, one action per step, one concurrency, exact tool-and-argument scoring, independent schema validation, and closed loop state assertions. Mobile selections made by the optional lexical guard are reported separately from the learned dense selector; use mobile_guard=0 for a no-guard run, or add selector=retrieval for retrieval-only or selector=retrieval_then_dense to retrieve ten candidates before dense scoring.
