Pipeline

Three stages, one spine

Each stage answers a different question, and each is only worth running if the one before it succeeded. Every stage writes a loss record per step while it trains, so a live run and a finished one are read the same way.

Results

The ten-benchmark average

The headline number is the mean step-success rate — function name and every argument correct — across AndroidControl, Mind2Web, ToolACE, xLAM, BFCL, AgentNet, ToolBench, ToolSandbox, MCP-Atlas and MobileActions. Open baselines all received the same fine-tuning recipe, so the table varies the model and not the method.

Where the points come from

Step-success by suite for the reference models. A low column is a capability gap, not a scoring artefact — AgentNet and MCP-Atlas are hard for everything at this size.

Curves read from runs/<stage>-la-<tier>/curve.jsonl; benchmark rows from results/evalsuite-full/*.json. Suites marked evaluation-only never enter a training split. Numbers on this page are measured, not projected — a stage that has not run says so.
